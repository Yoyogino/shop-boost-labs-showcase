# Security

## Reporting a vulnerability

Please do **not** open a public GitHub issue for a suspected security vulnerability.

Contact:

**shopboostlabs8@gmail.com**

Include:
- the affected public showcase page or component
- a concise description of the issue
- reproduction steps when safe
- screenshots or logs only if they contain no secrets or personal data

Do **not** send:
- passwords
- API keys
- access tokens
- database credentials
- Shopify secrets
- supplier credentials
- private keys

## Scope

This public repository is a sanitized showcase and documentation project. Production Shopify application source code, credentials, private infrastructure details, and merchant data are intentionally excluded.

If a report concerns a production Shop Boost Labs application, identify the app name and affected workflow without publishing sensitive details in a public issue.

## Disclosure

Please allow reasonable time for investigation and remediation before public disclosure.
