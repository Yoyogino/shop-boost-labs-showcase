# Contributing

Thanks for your interest in Shop Boost Labs.

This public repository is a showcase and collaboration surface. The production Shopify app repositories remain private.

## Good contributions

Examples:
- documentation improvements
- typo fixes
- accessibility suggestions
- public-site UX feedback
- architecture-documentation improvements
- non-sensitive feature ideas

## Do not submit

Do not include:
- copied private application source code
- .env files
- passwords or credentials
- database URLs
- Shopify secrets
- supplier credentials
- access tokens
- merchant or customer data
- internal incident information

## Security reports

Do not use public issues for vulnerabilities. Follow the instructions in SECURITY.md.
