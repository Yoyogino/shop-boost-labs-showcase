# Public Release Checklist

Run this checklist before adding any new file, screenshot, demo, or document to this public repository.

## Text / code
- [ ] No `.env` file or environment-variable value
- [ ] No database URL, username, or password
- [ ] No Shopify secret or access token
- [ ] No supplier credential
- [ ] No API key
- [ ] No private key
- [ ] No merchant or customer data
- [ ] No private operational source copied from production app repositories

## Images / video
- [ ] No API keys, tokens, passwords, or connection strings visible
- [ ] No browser address bar exposing sensitive query parameters
- [ ] No private dashboard IDs or internal incident evidence
- [ ] No personal or merchant data
- [ ] Media represents the intended public product workflow

## Repository
- [ ] README still describes current public status accurately
- [ ] SECURITY.md remains present
- [ ] CONTRIBUTING.md remains present
- [ ] Private production repositories stay private
- [ ] NexaExchange remains outside this repository

If there is any doubt, keep the material private until it is reviewed.
